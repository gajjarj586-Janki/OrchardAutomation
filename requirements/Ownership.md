Target URL: "https://dev.hyundai.com.au/au/en/crm-ownership-update"
 
## Description

Successful Ownership Update with valid date

Navigate to the Ownership Update form.
1. Add "KMHJT81BLCU374044" VIN 
2. Click Check
3. Select "No" to "Do you still own this vehicle?*"
4. Fill in all required fields.
5. Select a valid Month and Year for "When did you sell/stop owning this vehicle?".
6. Submit the form.
